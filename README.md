# 💸 Spendly — Modern Expense Tracker

Spendly is a beautiful and responsive expense tracking web app designed to help users manage their personal finances easily.

## 🚀 Features

- ➕ Add Income & Expenses
- 📊 Donut Chart Analytics
- 💰 Live Balance Calculation
- 🗂 Category-based Transactions
- 📅 Monthly Navigation
- 🔍 Filter Income & Expenses
- 💾 Local Storage Support
- 📱 Fully Responsive UI
- 🎨 Modern Minimal Design
- ⚡ Fast & Lightweight

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API
- Canvas API
